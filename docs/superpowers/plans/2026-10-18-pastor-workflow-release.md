# 목회자 실사용 검증과 첫 GitHub 배포 계획

목표: 제공된 악보를 브라우저에서 직접 올려 무료 인식·전조·절후렴 구분·송폼·PNG/TXT 저장까지 시험하고, 실제로 막힌 부분을 수정한 뒤 그림 안내서와 소스·Mac 시험판을 Harkamont/worship-note에 공개한다.

공개 원본은 허용 목록으로 따로 구성한다. 개인 키·설정·업로드 악보·실측 표본은 포함하지 않는다. 공개 스크린샷은 직접 작성한 연습악보로 촬영하고, 실제 사용자 악보의 검사 결과는 비공개 작업 폴더에 기록한다.

- [x] 현재 소원 작업을 백업하고 제공된 PNG 악보를 기본 무료 방식으로 업로드해 결과를 확인한다. 음표·가사·코드 누락은 실제 상태대로 기록한다.
- [x] 시작 사용자 관점에서 전조·분할·송폼·저장까지 조작한다. 구간 선택/악보 전체 마디 번호, 빈 가사 TXT, 한 번에 가사 입력 등 확인된 막힘만 작은 수정으로 고친다. 기능 변경은 먼저 실패를 확인하는 테스트를 작성한다.
- [x] 직접 작성한 연습용 이미지도 같은 절차로 읽어 인식과 수동 수정 과정을 촬영한다. 미리 만든 결과를 이미지 인식 결과인 것처럼 제시하지 않는다.
- [x] 한국어 단계별 가이드(HTML/PDF/Markdown)와 README를 실제 버튼·제약·출력 차이에 맞춰 작성한다. GUI에서 단계별 PNG 캡처를 저장한다.
- [x] 가이드 이미지의 공개 경로만 소스 ZIP에 허용하고 비밀키·개인경로 검사와 CI 권한을 점검한다. 별도 공개 스냅샷을 만들고 코드를 검토한다.
- [ ] 웹/데스크톱/유형별 테스트와 새로 푼 Mac 실행본을 검사한다. 원래 작업을 복원하고 배포용 파일 해시를 확인한다.
- [ ] 허가된 Harkamont/worship-note 공개 저장소와 GitHub Release에 소스·Mac 시험판·가이드를 올리고 실제 다운로드/README 이미지를 확인한다.

가사/코드 무료 OCR은 글자 초안이며 음표에 자동 배치한 결과가 아니다. 가사 일괄 입력을 추가하면 입력한 글자를 음표 아래에 배치하는 보조 기능으로 명확히 설명하고, 음절 수가 맞지 않는 경우 적용 전에 확인한다. PNG는 곡의 구간을 한 번씩 싣고 부를 순서를 상단에 표시하며, TXT·MusicXML은 정한 순서와 반복을 반영한다.
