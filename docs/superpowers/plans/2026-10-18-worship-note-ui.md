# 워십노트 화면과 도움말 개선 계획

**목표:** 사용자가 지정한 따뜻한 체스트넛·골드와 정돈된 책 표지의 인상을 적용한다. 화면의 반복 설명을 필요한 곳의 한국어 도움말로 옮긴다. 앱의 새 이름은 워십노트다.

**구성:** 기존 React 화면·악보 렌더러·저장 형식은 유지한다. 색상과 서체는 공통 CSS로 관리하고, 설명은 HelpTip과 도움말 문구 모음으로 관리한다. 도움말은 키보드·마우스·터치에서 열리고 대화상자 안에서도 잘리지 않아야 한다.

- [x] 공통 화면: 아이보리 배경, 체스트넛 메뉴와 주요 버튼, 절제된 골드 표시, 제목·주요 버튼 명조체, 작은 입력·설명 고딕체. 악보는 흰 배경과 검은 음표 유지.
- [x] 설명 정리: 중복 안내, 모델명, 파일 상세 정보는 도움말/접힌 영역으로 이동. 유료 표시·실제 비용·오류·교체 위험은 해당 동작 옆에서 표시.
- [x] 도움말: 전조, 템포, 악보 크기, 마디 배치, 절·후렴, 송폼, 가사 내보내기, XML, 작업 파일, 저장 위치, 무료 인식, AI, 멜로디 추출, 마디 보완을 자연스러운 한국어로 작성.
- [x] 브랜드: 화면 제목·로고·도움말·공개 문서를 워십노트로 변경. 기존 사용자 저장 폴더와 데이터 식별자는 유지.
- [x] 검증: 도구 설명의 키보드/터치/닫기 동작과 화면 가장자리·대화상자 배치 테스트. 1280px 기본 화면·좁은 화면·확대 사용을 브라우저에서 확인. 기존 소원 작업은 백업 후 시험하고 복원.
- [x] 배포: 기능 검사와 빌드 후 새 Mac 실행본·공개 소스·화면 캡처를 outputs에 저장. AI 요청은 하지 않는다.

기본 화면에 보이지 않는 설명도 도움말에서 바로 찾을 수 있어야 한다. 골드는 작은 본문 글자색으로 쓰지 않고 강조·테두리·선택 표시 중심으로 쓴다. 서체는 네트워크 없이 작동하도록 라이선스와 함께 포함한다.

검증 기록: 전체 웹 테스트412개, 도움말10개 포함; 데스크톱20개와 Python5개 통과. 1280×720·960×540 브라우저에서 배치·대화상자 도움말·Esc 동작을 확인했습니다. 유료 AI 요청은 하지 않았습니다.
낮은 창(560×200)에서 도움말을 End 키로 끝까지 스크롤하고 버튼 포커스가 유지되는 것을 확인했습니다. 일반 Python 보조 검사11개도 통과했습니다.
내보내기 메뉴 도움말을 눌러도 메뉴가 유지되도록 수정하고, Esc·JSON·PNG 다운로드를 실제 브라우저에서 확인했습니다. Mac ZIP 무결성, 포함 소스 SHA-256, 새로 푼 폴더의 두 서버·CPU 모델3개 실행 검사를 통과했습니다. 기존 소원 악보와 저장한 인식 결과는 변경하지 않았습니다.
