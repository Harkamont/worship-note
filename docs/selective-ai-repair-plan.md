# 선택한 마디만 AI로 보완하기

## 목적과 범위
사용자가 원본에서 표시한 1~4마디 이미지와 해당 마디의 음악 문맥만 AI에 보낸다. 무료 인식의 나머지 마디는 그대로 보관한다. 유료 요청은 버튼을 직접 누를 때 한 번만 수행하며 자동 재시도하지 않는다. 결과를 비교한 뒤 적용한다.

박자 검사로 찾을 수 있는 오류와 사람이 직접 찾은 음높이 오류를 구분한다. 자동 검사 통과를 정답 인식으로 취급하지 않는다. 원본 마디 분할 자체가 틀린 경우에는 다른 마디에 결과를 억지로 적용하지 않는다.

## 구현
1. lib/measure-crop.ts / source-region-picker.tsx: 원본 해상도에서 선택 영역을 PNG로 자른다. 크기·범위·면적 제한을 검사하며 전체 페이지로 자동 대체하지 않는다.
2. lib/musicxml-measure-repair.ts: 선택된 파트와 1~4마디 문맥을 생성한다. AI가 반환한 XML의 마디 수·번호·시간·음표 구조를 검사하고 선택 밖 원문을 보존한다. 잘못된 결과는 적용하지 않는다.
3. recognition.ts / api/repair-xml: 기존 제공자·키 설정과 취소·동시 처리 제한을 재사용한다. 작은 출력 상한, 낮은 추론 강도, 청구 메타데이터를 유지한다. 실패해도 보고된 청구를 반환한다.
4. musicxml-client.ts / measure-ai-repair.tsx: 원본에서 영역을 표시하고 미리 본 뒤 유료 버튼을 누른다. 후보 악보·비용을 확인한 뒤 편집기로 가져온다. 다음 보완은 마지막 적용 결과를 기준으로 한다.
5. review-workspace.ts / page.tsx: 처음 인식한 원본과 기존 멜로디 선택을 유지하며 마지막으로 적용한 부분 보완 XML·청구 내역을 별도로 보관한다. 수정 중인 초안도 기존 규칙에 따라 저장한다.
6. 실제 표본: 사용자가 준 10장에 대해 기존 무료/전체 AI 결과와 새 부분 AI 결과를 같은 수동 참조로 재평가한다. 전체 음표 참조가 없는 악보는 표본 수·범위를 표시한다. 선택 마디와 비선택 마디, 오류 탐지 재현율, 실패·중단 비용을 나누어 기록한다.

## 검증
- 선택 밖 XML 원문과 음표·가사·코드가 바뀌지 않는 회귀 검사.
- 교체할 마디 수/파트/번호/붙임줄/못갖춘마디/상속 조표·박자 검사 및 잘못된 요청의 무과금 거절.
- 취소·결과 적용 전 확인·기존 원본 보존·저장 후 복원 브라우저 시험.
- 유료 실험은 우선 총 $1의 보수적 예약 한도에서 순차 실행. 기존 전체 처리 기록은 과거 실행으로 명시하며 새 전체 페이지 요청으로 비용을 반복하지 않는다.
- 이번 개발 표본의 우위를 한국 교회 악보 전체의 인식률로 일반화하지 않는다.
