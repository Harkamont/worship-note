# 워십노트 시험판 배포 검증 기록

검사일: 2026-10-18 · 대상: 0.2.0-beta.6 Mac 시험판

처음 사용하는 사람이 이미지를 올려 전조·구간 나누기·가사 입력·송폼·파일 저장·다시 열기를 수행하는 흐름을 확인했습니다. 아래 수치는 작업에 사용한 Mac 한 대와 두 표본의 결과입니다. **전체 음표·가사·코드의 원본 일치율은 측정하지 않았습니다.**

## 무료 인식 표본

| 입력 | 공개 여부 | 처리 시간 | 반환한 마디 | 음표·쉼표 | 코드 | API 사용료 |
| --- | --- | --- | --- | --- | --- | --- |
| 자작 연습곡 ‘오늘의 찬양’ PNG | 공개 | 6.5초 | 16마디 | 64개 | 0개 | 0 |
| 사용자 제공 ‘소원’ 원본 이미지 | 비공개 | 8.7초 | 30마디 | 234개 | 0개 | 0 |

무료 경로는 로컬 음표 인식기를 사용했습니다. 이 검사에서 유료 AI를 요청하지 않았습니다. 마디·음표 개수는 반환한 데이터의 수이며, 원본과 맞은 음표의 수나 인식률을 뜻하지 않습니다. 두 표본의 처리 시간을 다른 이미지·Mac의 예상 시간으로 일반화하지 않습니다.

공개 연습 이미지는 앱을 위해 직접 만든 악보를 PNG로 내보낸 후, 그 이미지를 다시 업로드하여 인식했습니다. XML 파일을 곧바로 가져온 결과를 이미지 인식 결과로 표시하지 않았습니다. 사용자 제공 원본 이미지와 인식 파일은 공개 저장소·배포 파일에 포함하지 않습니다.

## 공개 연습곡의 작업 흐름

1. [연습용 PNG](images/practice-score.png)를 올리고 무료로 음표를 읽었습니다.
2. 편집기로 가져온 후 1마디 첫 박에 C, 2마디 첫 박에 F를 직접 입력했습니다. 무료 인식이 코드를 읽은 결과는 아닙니다.
3. C키를 D키로 바꾸어 멜로디와 직접 넣은 코드가 함께 전조되는 것을 확인했습니다. 두 코드는 D·G로 바뀌었습니다.
4. 1–8마디를 1절, 9–12마디를 후렴, 13–16마디를 브릿지로 나누었습니다. 전체 악보 기준 번호로 남은 부분을 계속 선택했습니다.
5. 부를 순서를 1절 → 후렴 ×2 → 브릿지 → 후렴으로 정했습니다.
6. 구간별 ‘가사 한 번에 넣기’에서 직접 입력하고 배치를 미리 본 뒤 적용했습니다. 가사 적용 전후에 음표의 음악 정보가 바뀌지 않았음을 확인했습니다.
7. 악보 PNG, 송폼에 맞춘 가사 TXT, 편집용 MusicXML, 작업 백업 JSON을 저장했습니다. MusicXML은 정한 순서와 반복에 따라 **24마디**로 출력되었습니다.
8. 작업 JSON을 다시 열어 편집 내용을 확인했습니다. 과정별 실제 화면은 [사용 안내](USER_GUIDE.md)에 있습니다.

PNG는 각 구간의 악보를 한 번씩 그리고 위쪽에 부를 순서를 표시합니다. TXT·MusicXML은 정한 순서와 반복을 반영합니다. PNG 본문이 반복 횟수만큼 늘어나는 것으로 안내하지 않습니다.

## 비공개 사용자 표본 확인

‘소원’ 원본 이미지로 무료 인식·가사 수동 적용·순서 편집·파일 저장을 확인했습니다. 가사를 적용한 뒤에도 음표의 음악 정보는 유지되었습니다. 이 작업에서 저장한 MusicXML은 송폼에 따라 **46마디**로 출력되었습니다.

30마디인 인식 원본이 46마디의 MusicXML로 출력된 것은 정한 순서와 반복을 반영했기 때문입니다. 인식기가 원본에 없는 마디를 추가로 읽었다는 뜻이 아닙니다. 이 표본의 악보 이미지·가사·작업 파일은 비공개로 보관합니다.

## 다른 악보를 읽어 볼 때의 보관 확인

기존 곡을 연 상태에서 연습 PNG를 새로 읽되 편집기로 가져오지 않았습니다. 결과 창의 현재 작업 JSON을 저장하고, 창을 닫은 뒤 새로고침했습니다. 자동 저장 파일과 다운로드 JSON 모두 기존 악보·원본 이미지·원본 XML·멜로디 선택·부분 수정 내역이 이전과 같음을 확인했습니다. 새 결과는 명시적으로 가져오기를 눌러야 현재 작업에 연결됩니다.

## 남은 한계

- 정답 악보와 모든 음높이·리듬·가사·코드·위치를 대조하는 정확도 평가는 수행하지 않았습니다. 원본 일치율이나 일정 정확도 이상의 성능을 약속할 근거가 아닙니다.
- 무료 음표 읽기는 가사·코드를 자동으로 붙이지 않습니다. 수동 입력한 코드를 인식 성과에 포함하지 않습니다.
- Mac 무료 글자 읽기는 한 변 2,500픽셀·400만 화소 이하 이미지에서만 사용할 수 있습니다. 큰 연습용 PNG에서는 해당 버튼이 비활성화되며, 이것은 무료 음표 읽기의 실패를 뜻하지 않습니다.
- 직접 가사를 배치해 개수가 맞아도 실제 부르는 위치가 맞는지는 원본과 비교해야 합니다.
- 편집기는 단선율·한 조성·한 박자 중심입니다. 잇단음표·32분음표·복잡한 시간 이동은 가져오지 못할 수 있습니다.
- Apple 개발자 서명·공증 전 Mac 시험판입니다. 다른 Mac의 실행 차단 여부와 Windows 호환성은 추가 검증이 필요합니다.

## 키와 개인 자료

API 키는 앱 설정 화면에서만 입력하고 공개 문서나 이슈에 붙여넣지 않습니다. AI 설정 JSON·앱 설정 폴더를 공유하지 않습니다. 공개 안내 화면은 자작 연습곡을 사용하며, 사용자 제공 원본과 개인 설정은 포함하지 않습니다. 작업 백업 JSON과 AI 설정 파일은 서로 다른 파일입니다.
