# 짧은 첫 마디·여러 성부 가져오기와 쉬운 한국어 화면

## 사용 목적
- 한국 교회에서 받은 이미지 악보를 무료로 읽고, 멜로디를 편집·전조·다운로드할 수 있게 한다.
- 첫 마디가 짧으면 원래 음표 길이를 보존한다. 여러 성부는 원본 파일을 보관하고 멜로디를 따로 만든다.
- 음표를 임의로 채우거나 삭제해서 오류를 숨기지 않는다. 인식 오류와 지원하지 않는 표기는 확인 항목으로 알린다.
- AI를 사용하는 버튼에는 추가 비용 여부와 실제로 보완하는 항목을 표시한다.

## 구현 순서
1. 마디별 실제 길이를 선택적으로 저장한다. 기존 파일은 종전대로 박자표 길이를 쓴다. 짧은 첫 마디 및 명시된 짧은 마디의 읽기·편집·전조·재출력을 확인한다.
2. 여러 성부의 원본을 보존하면서, 같은 보표의 높은 선율을 고르는 옵션과 원래 성부를 직접 고르는 옵션을 제공한다. 잘못 읽은 리듬·조표는 숨기지 않는다.
3. 편집 화면과 표시 간격에 실제 마디 길이를 반영한다. 가져오기 실패는 원본 비교 및 다운로드를 유지하며 이유를 설명한다.
4. 무료 읽기, AI 가사·코드 보완, AI 전체 읽기를 각각 효과·비용·주의할 점과 함께 안내한다. 송폼 등 용어를 한국 교회에서 익숙한 표현으로 바꾼다.
5. 회귀 검사와 실제 웹 PNG/JPG 두 악보의 브라우저 가져오기·전조·저장·다시 열기를 확인한다. 인식률 개선을 측정하지 않은 기능에는 정확도 향상을 주장하지 않는다.
6. 검증 결과와 소스/맥 실행본을 새 시험판으로 제공한다. 공개 저장소 배포나 유료 AI 요청은 이번 작업에 포함하지 않는다.

## 통과 기준
- 4/4의 1박 못갖춘마디가 1박 그대로 편집·재출력된다.
- 여러 성부를 가진 33마디 PNG 결과가 원본을 보존하고 멜로디로 열린다.
- 오류가 남은 4부 JPG는 오류 위치·이유를 분명히 안내하며 자동으로 맞는 악보라고 취급하지 않는다.
- 유료 방식에서 비용 미확인은 0원과 구분한다. 무료 방식은 API 연결 없이 작동한다.
- 테스트용 자료와 API 키가 공개 소스 묶음에 포함되지 않는다.
